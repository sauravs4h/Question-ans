## Q.1 "this" keyword in javascript
### Ans. 
In JavaScript, the "this" keyword refers to the object that is currently executing or being referenced within a function or method. The value of "this" is determined by how a function is called.

The behavior of "this" can vary depending on the context in which it is used. Here are some common use cases:

1. Global Scope: In the global scope (outside of any function), "this" refers to the global object. In a web browser, the global object is typically the "window" object.

2. Function Context: When "this" is used inside a regular function (not an arrow function), its value depends on how the function is called. If the function is called as a method of an object, "this" refers to the object itself. For example:

```javascript
const obj = {
  name: 'John',
  sayHello: function() {
    console.log('Hello, ' + this.name);
  }
};

obj.sayHello(); // Output: Hello, John
```

In this example, when the "sayHello" method is called on the "obj" object, "this" refers to the "obj" object, so "this.name" accesses the "name" property of "obj".

3. Constructor Functions: When a function is used as a constructor function with the "new" keyword, "this" refers to the newly created instance of the object. The constructor function is used to create new objects based on a template. For example:

```javascript
function Person(name) {
  this.name = name;
}

const john = new Person('John');
console.log(john.name); // Output: John
```

In this case, "this" inside the "Person" constructor refers to the newly created object that is being assigned the "name" property.

4. Explicit Binding: JavaScript provides methods like "call()" and "apply()" that allow you to explicitly specify the value of "this" within a function. For example:

```javascript
const obj1 = { name: 'John' };
const obj2 = { name: 'Jane' };

function sayHello() {
  console.log('Hello, ' + this.name);
}

sayHello.call(obj1); // Output: Hello, John
sayHello.call(obj2); // Output: Hello, Jane
```

In this case, the "call()" method is used to invoke the "sayHello" function with "obj1" and "obj2" as the context for "this".

5. Arrow Functions: Arrow functions have a different behavior for "this" compared to regular functions. They lexically capture the value of "this" from their surrounding context. In other words, "this" inside an arrow function refers to the same "this" value as the surrounding code. For example:

```javascript
const obj = {
  name: 'John',
  sayHello: function() {
    setTimeout(() => {
      console.log('Hello, ' + this.name);
    }, 1000);
  }
};

obj.sayHello(); // Output: Hello, John (after a 1-second delay)
```

In this example, the arrow function inside the "setTimeout" callback captures the "this" value from the surrounding "sayHello" method, so "this.name" accesses the "name" property of the "obj" object.

These are some of the common scenarios where the "this" keyword is used in JavaScript. It's important to understand the context in which "this" is being used to correctly interpret its value.

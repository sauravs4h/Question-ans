## Q.1 create a middleware function that check if a user's session exist. If it does not exist, It return a 401 Unauthorized error. if the session exists, it check if the currrent time is greater than the session,s expiration time. if it is, it return a 401 Unauthorized error. if the session is still valid , It call the next() function to move on to the next middleware function.

### Ans 
Sure! Here's an example of a middleware function in Node.js that checks if a user's session exists, verifies its expiration time, and returns a 401 Unauthorized error if necessary:

```javascript
function sessionMiddleware(req, res, next) {
  const session = req.session; // Assuming the session is stored in req.session

  // Check if session exists
  if (!session) {
    return res.status(401).json({ error: 'Unauthorized - Session not found' });
  }

  const currentTime = Date.now();
  const expirationTime = session.expirationTime; // Assuming the session expiration time is stored in session.expirationTime

  // Check if the current time is greater than the session's expiration time
  if (currentTime > expirationTime) {
    return res.status(401).json({ error: 'Unauthorized - Session expired' });
  }

  // Session is still valid, call next() to move on to the next middleware
  next();
}
```

This middleware assumes that the session information is stored in the `req.session` object and that the expiration time of the session is stored in `session.expirationTime`. You may need to adapt the code based on how your session is implemented and where the relevant information is stored.

Remember to place this middleware function before the routes that require authentication in your Express application. You can use it like this:

```javascript
app.use(sessionMiddleware);

// Your protected routes go here
app.get('/protected-route', (req, res) => {
  // Handle the protected route logic
});
```

Make sure you have the necessary dependencies and session handling set up in your Node.js application for this to work correctly.

## Q.2 how do you pass data between middleween function?

### Ans  

In Node.js, you can pass data between middleware functions using the `req` (request) and `res` (response) objects. The `req` object is typically used to store and pass data between middleware functions.

Here's an example of how you can pass data between middleware functions:

```javascript
function middleware1(req, res, next) {
  req.customData = 'Some data'; // Storing custom data in req object
  next();
}

function middleware2(req, res, next) {
  console.log(req.customData); // Accessing custom data from req object
  next();
}

app.use(middleware1);
app.use(middleware2);
```

In the above example, `middleware1` sets a custom data value `'Some data'` in the `req.customData` property. This data can then be accessed in `middleware2` by accessing `req.customData`.

You can also modify the data in one middleware and have the modified data available in subsequent middleware functions:

```javascript
function middleware1(req, res, next) {
  req.customData = 'Some data';
  next();
}

function middleware2(req, res, next) {
  req.customData += ' modified';
  next();
}

function middleware3(req, res, next) {
  console.log(req.customData); // Accessing modified data from req object
  next();
}

app.use(middleware1);
app.use(middleware2);
app.use(middleware3);
```

In the example above, `middleware1` sets the initial value `'Some data'` in `req.customData`, then `middleware2` modifies it by appending `' modified'`. Finally, `middleware3` accesses the modified data and logs it to the console.

By utilizing the `req` object, you can pass data between middleware functions in a Node.js application.




## Q.3 create a MongoDb collection using Nodejs and insert a new document into the collection.

### Ans 

To create a MongoDB collection using Node.js and insert a new document into it, you'll need to follow these steps:

1. Install the MongoDB driver for Node.js using npm:

```bash
npm install mongodb
```

2. Set up a connection to your MongoDB database:

```javascript
const { MongoClient } = require('mongodb');

const uri = 'mongodb://localhost:27017'; // MongoDB connection URI
const client = new MongoClient(uri);

async function connect() {
  try {
    await client.connect();
    console.log('Connected to MongoDB');
  } catch (error) {
    console.error('Failed to connect to MongoDB', error);
  }
}

connect();
```

Make sure to replace `'mongodb://localhost:27017'` with the appropriate connection URI for your MongoDB database.

3. Create a new collection and insert a document:

```javascript
async function createDocument() {
  try {
    const database = client.db('yourDatabaseName'); // Replace 'yourDatabaseName' with your actual database name
    const collection = database.collection('yourCollectionName'); // Replace 'yourCollectionName' with your desired collection name

    const newDocument = {
      name: 'John Doe',
      age: 30,
      email: 'john.doe@example.com'
    };

    const result = await collection.insertOne(newDocument);
    console.log('New document inserted:', result.insertedId);
  } catch (error) {
    console.error('Failed to insert document', error);
  } finally {
    client.close();
    console.log('Connection closed');
  }
}

createDocument();
```

Replace `'yourDatabaseName'` with the name of your MongoDB database and `'yourCollectionName'` with the name you want to give to your collection.

In the above example, a new document is created with the fields `name`, `age`, and `email`. The `collection.insertOne()` method is used to insert the document into the specified collection. The `result.insertedId` property contains the `_id` of the inserted document.

Remember to handle errors and close the MongoDB connection properly in a production environment.

That's it! You have created a MongoDB collection using Node.js and inserted a new document into it.


## Q.4 how can the Eval command be used to execute Lua scripts in Redis?

### Ans

To execute Lua scripts in Redis using the EVAL command, you can follow these steps:

1. Connect to your Redis server using a Redis client library or the Redis CLI.

2. Prepare your Lua script as a string. The script can contain Redis commands and Lua code. For example:

```lua
local key = KEYS[1]
local value = ARGV[1]

redis.call('SET', key, value)
return redis.call('GET', key)
```

In the above example, the Lua script takes a key and value as arguments, sets the key-value pair in Redis, and then retrieves the value for the given key.

3. Use the EVAL command to execute the Lua script. The syntax for the EVAL command is as follows:

```redis
EVAL script numkeys key [key ...] arg [arg ...]
```

- `script` is the Lua script as a string.
- `numkeys` is the number of Redis keys being passed to the script.
- `key [key ...]` are the Redis keys accessed by the script.
- `arg [arg ...]` are the arguments passed to the script.

Here's an example of using the EVAL command to execute the Lua script mentioned earlier:

```redis
EVAL "local key = KEYS[1]\nlocal value = ARGV[1]\n\nredis.call('SET', key, value)\nreturn redis.call('GET', key)" 1 mykey "myvalue"
```

In the above example, the EVAL command is used to execute the Lua script. The script takes one key (`mykey`) and one argument (`myvalue`) and performs the desired Redis operations.

The result of the EVAL command will be the return value of the Lua script, which can be captured and used as needed.

Note that the EVALSHA command can also be used to execute preloaded Lua scripts in Redis. It works similarly to EVAL but uses the SHA1 hash of the script instead of the script itself.

Make sure to handle any errors that may occur during script execution and handle the Redis responses accordingly.

That's how you can use the EVAL command to execute Lua scripts in Redis!
